# Practicum_calculator
Программа для выполнения математических операций с простыми числами, с плавающей точкой и дробными числами

## Особенности программы:
* Поддержка всех типов математических операций:
    * сложение
    * вычитание
    * умножение
    * деление
    * возведение в степень.
* Поддержка
