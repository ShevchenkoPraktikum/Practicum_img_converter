# Practicum_calculator
Программа для выполнения математических операций с простыми числами, с плавающей точкой и дробными числами

## Особенности программы:
* Поддержка всех типов математических операций:
    * сложение
    * вычитание
    * умножение
    * деление
    * возведение в степень.
* Поддержка следующих типов чисел:
    * double
    * float
    * uint8_t
    * int
    * int64_t
    * size_t
    * Рациональные (дробные) числа

## Как разработана программа:
Разработано на языке C++ с использованием фремворка Qt для реализации графического интерфейса.
