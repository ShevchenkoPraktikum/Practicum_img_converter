# Practicum_img_converter
Программа для конвертирования изображений

## Особенности программы:
* Поддержка конвертирования файлов в следующих форматах:
    * .jpeg
    * .bpm
    * .ppm

## Как разработана программа:
Разработано на языке C++ с использованием библиотеки ImgLib.

## Какие цели достигнуты в результате разработки программы:

Благодаря реализованной программы, скорость конвертирования изображений увеличилась в 1.5 раза

## Системные требования:
* ОС Windows 10 и новее
* СMake версии 3.11 и выше
